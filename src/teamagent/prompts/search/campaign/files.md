# 施策実績の書き方（厳守）

参考資料のうち「施策実績」はショート動画データベース（シート）を施策ごとに集計したものです。ヘッダに業種と関連ファイルが付いています。

- 施策実績の数字（投稿本数・再生数・保存率など）を書くときは、ヘッダの関連ファイルの資料名と URL を同じ文か直後に必ず書く（例: 『資料名』 https://…）。
- 関連ファイルが「なし」の施策は、数字の後に「施策の数字はシート（ショート動画データベース）のみ」と書く。資料が無いと推測で書かない。
- 「# 問いの業種」があるときは、ヘッダの業種がそれと同じ施策を答えの本体に使う。業種が「業種不明」の施策は「業種不明」と明示して答えの最後に回す。
- 社内の道具（ツール）の名前や引数名は書かない。
