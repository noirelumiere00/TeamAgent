## 出力契約（厳守）

**JSON オブジェクトだけ**を出力すること（前後に説明文・コードフェンス・表を付けない）。形式:

```
{
  "placeholders": { "1": "…", "2": "…", … },
  "citations_per_placeholder": { "23": ["https://…"], "28": ["https://…","https://…"] },
  "skipped_placeholders": [ { "id": 41, "reason": "要確認（データ未検出）" } ]
}
```

- `placeholders` に **埋めた ID のみ**、未検出は `skipped_placeholders` に積む。
- **埋めた ID + skipped ID の和集合 = 95 個（{1}–{103}＼{48}–{55}）を完全に覆う**こと。
- 欠番 {48}–{55} は使わない（PR ワード 9 案は {47} の 1 セルにまとめて投入する設計）。

## PR ワード（{46}/{47}/{56}）— 高度化ルール

- {46} は **商品名・カテゴリ名を含めない造語**（「ガチ中華」「タイパ」の系統）。USP×社会背景×インサイトの掛け合わせで、SNS で自然に語られる「リズムと拡張性」を持たせる。
- {47} は **別案 9 つ＋各選定背景**を 1 セルに整形して投入（{47}-{51}=既存語の組合せ系 5 案、{52}-{55}=新造語系 4 案。各案に約 500 字の選定背景）。
- {56} は {46} を選定した背景を分析結果から 500 文字程度で説明。
- 9 案の上位 3 案を {7}/{9}/{11} の見出し、具体イメージを {8}/{10}/{12} に昇格させる。

## マルチコンテキスト設計

- 各メディア・界隈の訴求メッセージは似た内容にせず、文脈ごとに多様化する。
- パブリシティ文脈の「トレンドワード」と界隈文脈の「界隈言語」は**必ず異なる単語**にする。
- {96}-{103} の動画案は「商材に合わせた利用シーン・感情の文脈（〇〇文脈）」を必ず策定し、「何の文脈を狙ったか」を明記する。

## 絶対遵守ルール（ハルシネーション抑制）

1. **citations**: URL は**研究素材に実在するもののみ** `citations_per_placeholder` に転記する。推測 URL・推測数値（TikTok 件数/記事件数）は禁止。
2. **データ未検出**: 研究素材に根拠がない placeholder は **埋めずに** `skipped_placeholders` に `{"id": N, "reason": "要確認（データ未検出）"}` で積む（空文字で埋めない）。
3. 競合名・メディア名・界隈の数値は研究素材からのみ。無ければ skip。
4. 本文はテキスト（箇条書き等）。表は使わない。
