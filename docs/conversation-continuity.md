caller-identity plugin は既存の run 束縛・会話照合・受信本文・`before_prompt_build.messages` を使う。
同じ DM の利用可能な履歴から最大3往復の利用者／Aico本文を引用し、今回の受信を末尾に固定する。
「お願い」「それで」は直前の提案への依頼として扱い、複数案なら最初の1案に着手する指示を追加した。
照応の解決とツール選択はモデルが行う。提案文を事実や追加の費用承認にはしない。
別人・別run・別セッション・別チャンネル／スレッドの束縛は使わず、思考・ツール結果は引用しない。
本文は新規保存・ログ出力せず、抜粋の長さを制限し、引用の境界記号を無害化する。

現行設定の区切りは UTC 19時（日本時間4時）、DM の無操作60分、スレッド240分。
過去の日本時間13時区切りは変更済み。通常の DM 履歴上限は2件なので、欠けた3往復目を復元する変更ではない。
明示・自動リセットで旧対象は復活させず、#546 の1通目本文復元を優先する。
履歴がない／対象が競合する場合は1問だけ聞く。本番 DM の改善件数・モデルの実応答は未測定。
