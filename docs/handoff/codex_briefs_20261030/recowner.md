あなたは teamagent リポジトリの開発者。作業場所はこの worktree（origin/dev 起点）。日本語で報告する。
前の PR（#789）で recommend（src/teamagent/skills/recommend）は「似た過去の提案書」を他社優先・Drive 原本リンク付きで返すようにし、リンクを解決できない候補は載せないようにした。小俣さんの判断で、これを変える:
- リンクが無い候補も載せる。形は「**案件名（年月）**＋似ている点 1 行＋『資料はナレッジに登録されていません。担当の ◯◯ さんに確認してください』」。
- 担当は、その候補の元データから取る: Slack 由来なら投稿者（アップロードした本人）、案件データ（営業 FB・案件の正本）由来なら案件の担当者。metadata にある既存の項目を使い、新しい取り込みは作らない。氏名の表示形式は既存の答えと同じ（姓＋さん 等）。担当が分からなければ「担当者を確認できませんでした」と書く。
- 並び順はリンクがあるものを先に。合計は最大 3 件のまま。
- 資料が未登録の候補を数えるログ（イベント 1 行・案件 ID と担当の有無だけ・氏名や本文は出さない）を足す。後でナレッジの登録漏れの集計に使う。
テスト: リンク無し候補が載る・担当の取り方（Slack 投稿者／案件担当／不明）・並び順・ログ。`uv run --extra dev --extra mcp --extra media pytest -q -n auto tests/skills/recommend tests/skills/search` と ruff・mypy。
禁止: git commit・push、AWS・DB の実接続、.env・secrets の読み取り。顧客名・氏名を報告に書かない。差分は小さく。最後に変更点・テスト結果を短く。
