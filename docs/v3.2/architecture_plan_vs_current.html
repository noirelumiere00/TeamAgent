ARCHITECTURE — PLAN vs REALITY

TeamAgent アーキテクチャ：計画(v2.2) × 現状(v3.x) 比較 「基本設計はこの通りになっているか？」への回答と、差分の TODO

比較対象：アーキテクチャ図書 v2.2（2026-05-13）　×　現行 main 実装（2026-06-05 時点／全機能マージ済・831テストpass）

結論：いいえ。基本設計は「意図的に大きくピボット」しています。

計画(v2.2) ＝ AWS サーバーレス（Lambda×4 + Fargate + SQS + API Gateway + RDS Proxy）× 5機能。
現状(v3.x) ＝ 単一プロセス常駐Bot × EC2 1台 ＋ ルールベース・ローカル埋め込み × 12スキル。

方向性は同じ（Slack入口・pgvector ナレッジ脳・Claude/Gemini 併用）ですが、実行基盤は計画の重厚なサーバーレス群を採らず、20名/同時4の実規模に合わせて単一プロセスへ簡素化。一方で検索（Rerank＋行レベル権限）・PR動画ドメイン（VSEO/動画チェック/TikTok）・雑談は計画を超えて厚く、②朝メール／⑤週次サマリー／多経路リサーチ／connect本番配線が未実装、という構図です。
