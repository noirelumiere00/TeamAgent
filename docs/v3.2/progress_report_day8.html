4. 検索精度評価 (Gold Set 25 ケース)

Sprint 4 各機能の効果を 同一の 25 ケース gold set で A/B 比較。これにより 1 件の anecdote ではなく統計的に改善を立証する。

構成flagstop-1top-5MRR$/querylatency
baseline Rerank OFF / prompt v1 20% 40% 0.27 $0.012 9.2s
+ Rerank USE_COHERE_RERANK=true 52% 52% 0.52 $0.015 11.4s
Day 8 Full 部分 + FB Drive Match + prompt v2 59%* 59%* — $0.030 36s

* Day 8 Full は 22/25 ケースまでの部分集計 (時間切れ中断)。残り 3 ケース実行後に正式値確定予定。

主要な改善ポイント

  • Cohere Rerank 単体で top-1 hit rate を 2.6 倍 (20% → 52%) — Anthropic 公式ベンチの「-67% 失敗率」とほぼ整合
  • 「日本ガイシのケイパ」が rank 6 → rank 1 に救済 — dense retrieval の固有名詞弱点を Cross-Encoder Rerank で補強
  • 追加コストは + $0.003 / query、月予算内 ($21/月 想定 @ 10,560 query)
  • レイテンシ + 2.2s — Rerank API 呼び出しコスト
