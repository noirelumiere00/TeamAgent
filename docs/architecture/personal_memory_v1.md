# Aico「DM 本人メモ v1」利用・運用ガイド

- 決裁: 2026-09-25
- 対象: Aico と利用者本人の **1 対 1 DM だけ**
- 目的: 使うほど本人に合う返事にする
- 返事を作るもの: 現行 Aico（OpenClaw の Haiku）。Hermes は覚える内容を整理する係だけ

## 何を覚える／覚えない

| 覚える | 覚えない |
|---|---|
| 返事の長さ、言い回しの好み | DM のメッセージ本文そのもの、逐語の引用 |
| よく扱う顧客名、商材名 | 先方担当者の個人名 |
| よく使う資料の型 | URL、電話番号、メールアドレス、password・秘密情報 |
| 仕事の進め方、繰り返しの修正 | prompt injection、転送/引用/長文/コード |
| **社内の同僚の名前** | チャンネル、グループ DM（mpim）の内容 |

人名は敬称・役職（「さん」「様」「氏」「部長」など）を手掛かりに判定する。社内の同僚かどうかは Aico が持つ在籍者名簿で確かめ、名簿に無い名前は保存しない。敬称の無い人名は検出しきれないことがあるため、気になる項目は「○番を忘れて」で消す。会話本文は Personal Sessions / FTS5 にも保存しない。

## DM で使える 5 つの操作

| 送る言葉 | 動作 |
|---|---|
| 「何を覚えてる？」 | 番号つきの一覧と、管理者に閲覧された累計回数を表示する |
| 「○番を忘れて」 | 指定した 1 項目を削除する |
| 「覚えるのを止めて」 | 学習と返事への適用を止める。内容は残す（凍結） |
| 「記憶を再開して」 | 凍結中の学習と適用を再開する（普段の依頼と区別するため、この言葉だけで送る） |
| 「覚えたことを全部消して」 | 確認後に全項目を物理削除し、凍結する。自動では再開しない |

「全部消して」は誤操作防止のため、Aico の確認に 10 分以内に答えた場合だけ実行する。削除後に再開するには「記憶を再開して」と明示する。

## 管理者閲覧と記録

v1 で内容を見られる管理者は **小俣さん 1 名だけ**である（本人メモ専用の管理者リストで管理し、利用状況画面の管理者とは分ける）。閲覧口は connect_web の管理画面だけで、「監査記録の追加 → 内容の表示」を 1 つの DB 関数で行い、次を記録する。

- 誰が見たか
- どの利用者を見たか（監査上は hash 化した識別子）
- 何件見たか、閲覧理由

監査記録にメモ本文は入れない。記録に失敗した場合は 503 とし、内容も件数も表示しない。本人は「何を覚えてる？」で管理者閲覧回数を確認できる。本人メモは本人への Aico の返事を良くする目的だけに使い、人事評価には使わない。

## 保持、凍結、削除

| 状態・事象 | 扱い |
|---|---|
| 通常 | 1 対 1 DM から学習し、次回以降の 1 対 1 DM だけで使う |
| 凍結 | 内容を残したまま、学習も利用も止める |
| 全削除 | 確認後に本人メモを物理削除し、凍結する |
| 退職 | Slack `users.info deleted=true` を確認したら本人メモを自動削除する |
| ゲスト化 | 自動削除せず凍結する |
| Slack API 失敗 | 退職と見なさず、削除しない |

本人メモを削除しても、次は別の保持機構のため直ちには消えない。

| 残る場所 | 期間 |
|---|---|
| RDS の自動バックアップ | 最長 7 日（`infra/terraform/rds.tf:115`） |
| AI（Bedrock）の呼出し記録 | 既定で有効・本文を含む・最低 60 日（`infra/terraform/variables.tf:183-198`、`infra/terraform/security.tf:372`）。削除の依頼では消えない |
| Slack の DM 履歴と Aico の会話記録 | 「何を覚えてる？」への返答などが残る。会話記録の保持期間は**未確認** |

学習中の DM 発話は MCP の揮発メモリに最大 10 分または 5 発話だけ置く。DB、アプリログ、CloudWatch、Sentry には出さず、再起動時は消える。Bedrock の呼出し記録が本番で実際に配送されているかは点灯前に読み取りで確認する。告知の「〇〇」（問い合わせ先・会話記録の保持期間）は点灯前に確定する。

## 学習開始前の告知文案

> 【お知らせ】Aico が DM であなたの「好み」を覚えるようになります
>
> Aico との 1 対 1 の DM でのやりとりから、あなたに合った返事をするために次のことを自動で覚えます。覚えるたびのお知らせはしません。このお知らせの次のメッセージから対象になります。
>
> ■ 覚えること  
> 返事の長さや言い回しの好み／よく扱う顧客名・商材名／よく使う資料の型／仕事の進め方／社内の同僚の名前（在籍者名簿に載っている人）
>
> ■ 覚えないこと  
> メッセージの本文そのもの／先方ご担当者の個人名／URL・連絡先・パスワードなどの秘密情報  
> チャンネルやグループ DM での発言は対象外です。
>
> ■ 使いみち  
> あなたへの Aico の返事を良くするためだけに使います。人事評価には使いません。
>
> ■ 見られる人  
> v1 では管理者の小俣さんだけが内容を見ることができます。閲覧はすべて記録され、あなたも閲覧された回数を確認できます。
>
> ■ 操作（Aico との DM で送ってください）  
> 「何を覚えてる？」……一覧と管理者の閲覧回数を表示します  
> 「3番を忘れて」……その項目を消します  
> 「覚えるのを止めて」……覚えることも使うことも止めます（内容は残ります）  
> 「記憶を再開して」……止めていた学習と利用を再開します  
> 「覚えたことを全部消して」……確認のあと、すべて消して停止状態にします
>
> ■ 消したあとも残るもの  
> システムのバックアップに最長 7 日、AI の呼出し記録に最低 60 日残り、この 2 つは削除のご依頼でも消えません。Aico との会話記録にも保持期間中は残ります（保持期間: 〇〇）。退職したときは本人メモを自動で消します。
>
> お問い合わせ: 〇〇

「保持期間」「お問い合わせ」は現時点で**未確認**。法務・総務確認と決裁者 GO の前に実値へ置き換え、未確定のまま送信しない。
